dynamics — multi-dimensional newton's laws & friction problems

Two objects, one string, one shared acceleration

Connect two objects with a string over a pulley and something convenient happens: whatever one does, the other must match — same speed, same acceleration, just possibly in a different direction. That constraint turns two separate free body diagrams into one solvable system. Add friction on one side and the problem becomes a genuine test of Newton's second law applied twice, then combined.

The constraint

An ideal string and pulley force both objects to share the same acceleration magnitude — that single fact is what lets you combine two separate equations into one.

Tension links them

Tension is the internal force each object exerts on the other through the string. It's the same throughout an ideal, massless string over a frictionless pulley.

One FBD each, then combine

Write F = ma separately for every object using its own free body diagram, then use the shared acceleration and shared tension to solve both equations together.

Block on a table, mass on a string

Block A sits on a table with friction. A string runs over a pulley at the table's edge down to hanging Block B. Block B's weight pulls the whole system, and friction under Block A fights back.

Static. Friction is holding Block A in place against Block B's pull.

Problem 2

Block A (5 kg, μ_k = 0.25) sits on a table, connected over a pulley to hanging Block B (4 kg). Find the system's acceleration and the string's tension.

m/s²

Show solution
System acceleration: a = (m₂g − μ_k m₁g)/(m₁+m₂) = (4×9.8 − 0.25×5×9.8)/9 = (39.2 − 12.25)/9 ≈ 2.99 m/s². Tension from Block B's equation: T = m₂(g − a) = 4×(9.8 − 2.99) ≈ 27.2 N (check with Block A: T = m₁a + μ_k m₁g = 5×2.99 + 12.25 ≈ 27.2 N ✓).

Problem 3

Block A (8 kg, μ_s = 0.5) sits on a table, connected to hanging Block B (3 kg). Find the driving force from Block B's weight, and the maximum static friction available — then determine whether the system moves at all.

N
N
Show solution
Block B's weight is the driving force: m₂g = 3 × 9.8 = 29.4 N. Maximum static friction on Block A is μ_s m₁g = 0.5 × 8 × 9.8 = 39.2 N. Since 29.4 N is less than 39.2 N, static friction can supply exactly what's needed to hold everything still — the system doesn't move.

Problem 4

Block A (4 kg) sits on a 20° frictional incline (μ_k = 0.15), connected over a pulley at the top to hanging Block B (5 kg), which pulls Block A up the slope. Find the system's acceleration and the string's tension.

N
Show solution
Along the incline, Block A feels gravity pulling it down-slope (m₁g sinθ ≈ 13.4 N) and kinetic friction also opposing its up-slope motion (μ_k m₁g cosθ ≈ 5.5 N). Combining both blocks' equations: a = (m₂g − m₁g sinθ − μ_k m₁g cosθ)/(m₁+m₂) = (49 − 13.4 − 5.5)/9 ≈ 3.34 m/s². Tension from Block B: T = m₂(g − a) = 5×(9.8 − 3.34) ≈ 32.3 N.
