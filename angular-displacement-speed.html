circular motion — angular displacement & speed

One spin rate, a different speed for everyone on board

Every point on a spinning rigid object — a fan blade, a record, a merry-go-round — shares exactly the same angular displacement and the same angular speed, no matter how far it sits from the center. But their actual, physical speed through space depends on that distance. This is the single most useful fact for connecting "how fast is it spinning" to "how fast is that specific point moving."

Angular displacement, Δθ

The change in angular position over some time interval. Positive for counterclockwise rotation, negative for clockwise — same sign convention as θ itself.

Angular speed, ω

How fast the angle is changing. Average angular speed is displacement over time; every point on a rigid rotating object shares the same ω.

ω_avg = Δθ / Δt

Linear (tangential) speed, v

The actual speed of a specific point, which does depend on its distance from the center — twice the radius means twice the speed, for the same ω.

v = rω

Problem 2

A fan blade completes 3 full revolutions in 2 seconds, spinning at a constant rate. Find its average angular speed.

rad/s
Show solution
3 revolutions is 3 × 2π = 6π rad of angular displacement, so ω = 6π / 2 = 3π ≈ 9.42 rad/s.

Problem 3

A point on the tip of that same fan blade sits 0.5 m from the center. Find its linear speed.

m/s
Show solution
v = rω = 0.5 × 9.42 ≈ 4.71 m/s.

Problem 4

A wheel's angular position changes from θ = 1.2 rad to θ = 4.8 rad over 1.8 s. Find its average angular speed.

rad/s
Show solution
Δθ = 4.8 − 1.2 = 3.6 rad, so ω_avg = 3.6 / 1.8 = 2 rad/s.
