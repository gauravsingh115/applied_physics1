Putting it all together: the vertical loop

Every circular motion problem reduces to the same move: draw the free body diagram, pick radial and tangential axes, and apply Newton's second law along the radial direction — ΣF_radial = mv²/r. The vertical loop is the classic test of this, because the answer changes with position: gravity sometimes helps supply the centripetal force, and sometimes fights against it.

Isolate the radial direction

At any instant, "toward the center" is a specific, well-defined direction. Every force gets projected onto it before anything else happens.

Gravity's role changes

On a vertical circle, gravity is constant, but the fraction of it that points toward the center depends entirely on where the object is in the loop.

Tension can't push

A string can only pull. If the radial equation ever demands a negative tension, the string has actually gone slack — the motion isn't circular any more.

Tension around a vertical loop

Move the ball to any position in the loop and set its speed there. The radial version of Newton's second law gives the string's tension at that exact instant.

Tension is largest at the bottom, where gravity fights the centripetal requirement, and smallest at the top, where gravity helps supply it.

A general strategy

The same four steps solve almost any circular motion problem, vertical loops included.

  1. Draw the free body diagram at the specific instant or position you care about — don't try to handle "the whole loop" at once.
  2. Identify the radial direction (toward the center) at that instant, and decompose every force onto it.
  3. Apply ΣF_radial = mv²/r, solving for whatever is unknown — tension, normal force, friction, or the speed itself.
  4. Sanity-check the sign. A string or rope can only pull (T ≥ 0); if your answer comes out negative, the assumed motion isn't actually possible.

Show solution
At the bottom, gravity points directly away from the center, so it fully opposes the centripetal requirement: T = mv²/r + mg = 0.5×16/1.2 + 0.5×9.8 ≈ 6.67 + 4.9 ≈ 11.57 N.

Problem 3

Using the same string and ball (r = 1.2 m), find the minimum speed at the top of the loop needed to keep the string taut (T ≥ 0 there).

m/s
Show solution
At the top, T = mv²/r − mg. Setting T = 0: v_min = √(gr) = √(9.8 × 1.2) ≈ 3.43 m/s.

Problem 4

Same ball and string (r = 1.2 m), now moving at 4 m/s through the side of the loop (90° from the bottom). Find the tension there.

Show solution
At the side, gravity is entirely tangential — none of it points toward the center, so T = mv²/r = 0.5×16/1.2 ≈ 6.67 N alone.
